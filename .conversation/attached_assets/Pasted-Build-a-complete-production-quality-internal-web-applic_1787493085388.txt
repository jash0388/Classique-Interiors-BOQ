Build a complete, production-quality internal web application for **Classique Interiors** based on the company's BOQ workflow.

This is an actual functional business application, NOT a UI mockup.

## 1. PURPOSE

The system should digitally manage the complete BOQ and project-costing workflow:

**Client Enquiry / RFQ → Drawings / Scope → Site Visit → Scope Understanding → Quantity Take-Off → BOQ Preparation → Vendor RFQ → Quotation Collection → Technical Comparison → Commercial Comparison → Negotiation → Final Rate Confirmation → Rate Analysis → Internal Cost BOQ → Internal Review → Management Approval → Client Proposal / BOQ → Client Review → PO / LOI → Project Budget Lock → Procurement / Site Execution / Subcontract → Actual vs BOQ → Variation → Measurement Sheet → RA Billing / Final Billing → Project Closure → Final Cost & Margin Review**

The application should make this process trackable, structured and searchable.

# 44. IMPORTANT CALCULATIONS

Implement accurate calculations.

### BOQ Amount

Quantity × Rate

### Total Cost

Material + Labour + Subcontract + Freight + Wastage + Site Overheads + Additional Costs

### Profit

Selling Price - Actual Cost

### Margin %

Profit / Selling Price × 100

### Variance

Actual Quantity - BOQ Quantity

### Cost Variance

Actual Cost - Budget Cost

### Vendor Savings

Original Quotation - Negotiated Quotation

All calculations should update automatically.
